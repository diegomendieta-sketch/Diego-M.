# Diego’s Codex Skills

All **61 local skill folders**, including 11 personal, 5 system, and 45 plugin skills. Snapshot: November 17, 2026. Active, legacy, and cached template skill folders are included.

The complete snapshot is stored in three ZIP archives to fit GitHub’s web uploader limits. Each archive preserves the original folder structure. Download **all three**, then extract them into the **same folder**:

| Archive | Contents |
| --- | --- |
| [codex-skills-core.zip](codex-skills-core.zip) | 41 personal, system, and non-template plugin skills; full index, manifest, file checksums, and notes |
| [codex-skills-templates-1.zip](codex-skills-templates-1.zip) | 10 template skills with reference files |
| [codex-skills-templates-2.zip](codex-skills-templates-2.zip) | Remaining 10 template skills with reference files |

After extraction, open `README.md` for the linked skill index. The files live under `skills/personal/`, `skills/system/`, and `skills/plugins/`. Scripts, references, assets, templates, tests, and supplied license files are included.

You can verify the downloads with [ARCHIVE_SHA256SUMS](ARCHIVE_SHA256SUMS). The extracted snapshot also includes `skills/SHA256SUMS`, covering the skill files. See the [manifest](manifest.json) and [sanitization notes](SANITIZATION.md).

## Configuration and privacy

Customer examples and staff names were anonymized in the public copies; deployment, spreadsheet, Slack, and personal path identifiers were replaced with configurable placeholders. Local originals were preserved. Replace placeholders with your own authorized configuration before using these skills.

Plugin connections, account permissions, credentials, runtime libraries, and unrelated project files are not included. Some skills need connected apps or an external runtime. The performance report skills require the separate `agent_report` project and current report-scope configuration.

Existing licenses and notices remain applicable. This snapshot grants no new blanket license to bundled material.
